✨ OneUI Designer — Elevate Your Samsung One UI 8.5 Experience! 🚀
Take full control of your Samsung Galaxy running One UI 8.5+ (Android 16+) with OneUI Designer — an all-in-one customization studio powered by LSPosed. Built with a sleek Material 3 Pitch-Black OLED UI, smooth spring animations, and scoped system hooks, it lets you personalize and inspect your device effortlessly.
🌟 Key Features
 * 🖼️ About Phone Media Banner: Personalize Settings → About phone with animated GIF, MP4, or MPV media banners and adjustable banner height and corner radius.
 * 🔋 Battery Studio & Cycle Diagnostics: Track Battery Health (BSOH/ASOC), Charge Cycle Count, Actual vs. Design Capacity (mAh), live wattage, and battery temperature with dual animated OLED gauges. Also adds a dedicated diagnostics section inside Samsung Settings → Battery information.
 * 🎨 SystemUI & Interface Tweaks: Customize Status Bar options (clock seconds, alignment, battery icon visibility, live network speed), Navigation Bar gesture hint/pill scale, Quick Panel blur, and notification shade transparency.
 * ⚡ WM Shell & Home Animations: Tune app opening/closing curves, transition duration scales, and One UI Home workspace blur effects safely without touching system_server.
 * 🏷️ Software Info Signature: Automatically displays your OneUI Designer signature inside Settings → About phone → Software information.
 * 🔄 Component Restart Manager: Safely restart SystemUI, One UI Home, or Samsung Settings individually with confirmation dialogs and status feedback—no full device reboot required.
⚠️ Known Bugs & Workarounds
 * 🌐 App Crash When Changing System Language: Switching system language while the app is open or cached can trigger a configuration reload crash.
   * Fix / Workaround: Turn off Haptic Feedback in your device settings (or disable the Quick Panel haptic tweak), force-close OneUI Designer, and reopen the app after changing the language.
 * 🈯 Incomplete Translation (Mixed English & Vietnamese UI): Some screens, labels, and battery diagnostic cards are currently in Vietnamese or mixed English/Vietnamese and have not been translated in full yet. Full localization is planned for a future update.
📋 Requirements & Credits
 * 🔑 Root Access Required: Root privileges (e.g., KernelSU) are required on the device to run LSPosed and access privileged system/battery nodes when needed.
 * 📱 Compatibility: Samsung Galaxy devices on Android 16+ (API 36) & One UI 8.5+ with LSPosed enabled (SystemUI, Settings, and One UI Home scopes active).
